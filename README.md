# ForgeMaster Web

Forge Master benzeri tarayıcıda çalışan idle demirci oyunu (basit prototip v0.1).

## Oynanış
- ⛏️ Maden kaz → 🪨 cevher
- 🔥 Erit (2 cevher → 1 külçe)
- ⚒️ Döv (külçe → altın + XP)
- Yükselt: kazma / örs / körük (idle gelir)
- Çağlar: Taş → Orta Çağ → Modern → Uzay → Kuantum (kazanç çarpanı artar)
- Otomatik kayıt + çevrimdışı kazanç (maks 8 saat)

## Çalıştır
`index.html` dosyasına çift tıkla. Kurulum gerekmez.
